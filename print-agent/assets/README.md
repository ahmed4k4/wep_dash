# Assets

Drop your icons here:

- `icon.ico` — installer + app icon (256×256 multi-size `.ico`).
- `tray.png` — system-tray icon (16×16 or 32×32 PNG).

Optional: if `tray.png` is missing the agent runs with an empty tray icon.
If `icon.ico` is missing, `electron-builder` uses the default Electron icon.
